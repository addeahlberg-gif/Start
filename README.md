# Startportal för Cloudflare Pages

Ladda upp `index.html`, `style.css`, `app.js` och `_headers` i roten av GitHub-repot.

Cloudflare Pages-inställningar:
- Framework preset: None
- Build command: lämna tomt
- Build output directory: `/`

All personlig data sparas i webbläsarens localStorage. Exportera en säkerhetskopia från portalen om du vill flytta inställningarna till en annan enhet.
